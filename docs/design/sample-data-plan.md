## 2. 方針

1. **架空の患者 6 人**（M3 の患者と EHR）。記録はすべてどれかの患者の EHR に結び付ける。
   - 患者 ID は `DEMO-01`〜`DEMO-06`。架空だと ID で分かるようにする。
   - anlage の患者は ID しか持たない（M3 計画 7.5 の問い 5）ので、氏名は持たせない。
   - 下の「人物像」は、この文書で臨床の目で読むための説明で、データには入らない。
2. **全体で 65 件**。いまの 6 件は、下の表に吸収する（170 cm・65 kg・22.5 は DEMO-04 に残す）。
3. **記録日をずらす**。期間は 2026-01〜2026-10。時刻は 09:00（日本時間）にそろえる。
   - フォーム経路のイベント時刻とコンポジションの時刻は保存した時刻（`app/lib/opt/composition_builder.rb:326`・`:333`）。
   - ローダーは、記録ごとに時刻を固定して保存する（実装の詳細は承認後に Red から決める）。
4. **値は合成**。傷病名は自由記述（DV_TEXT。フォーム経路と同じ）。
   - コードはいまのリポジトリにある ICD-11 MMS `5A11`（2型糖尿病）だけを使う（DEMO-01 の傷病と紹介状）。
   - ほかの病名にコードを付けるかは問い 2。
   - 検査は分析名と単位を自由記述で持つ。いまと同じ形で、JLAC 等のコードは付けない。
   - コンテンツ防火壁は変わらない。
5. **どの種類の値にも、当たる記録と外れる記録を入れる**。
   - 血圧は、低い・正常・高い（収縮期だけ高い、拡張期だけ高い、両方高い）を入れる。
   - 傷病は、確定・疑い・確度の記載なし（紹介状）を入れる。発症日時のある記録と無い記録、
     同じ語を含む別の病名（2型糖尿病と糖尿病性腎症）も入れる。
   - 検査は、空腹時血糖・HbA1c・クレアチニン・eGFR・LDL コレステロール・ヘモグロビン。
     同じ患者の時系列を入れる。
6. **紹介状は 2 件**。jp_referral は第 1 幕で壇上で登録するので、初期状態ではテンプレートを登録しない。
   いまと同じく RM グラフにだけ入れ、患者の EHR に結び付ける。
   - 1 件目は `skeleton.canonical.json` そのまま（X病院、2型糖尿病 5A11）。
   - 2 件目は同じ骨格を複製して、傷病名と紹介先を差し替える。fixture のファイルは変えない。
   - どちらも診断確度は書かない（確度を書かない文書の形）。
7. **データは宣言的に持つ**。
   - ローダーの中に、下の表と 1 行ずつ見比べられる定義（患者・日付・テンプレート・値）を置く。
   - 定義から記録を入れる手順は 1 つにする。

### 判定の目安（値を選んだ根拠。臨床の確定は人間）

- 血圧: 高い = 収縮期 140 以上 または 拡張期 90 以上。低い = 収縮期 100 未満。正常 = 収縮期 120 未満 かつ 拡張期 80 未満
- BMI の判定: 18.5 未満 低体重、18.5 以上 25 未満 普通体重、25 以上 30 未満 肥満（1度）
- 空腹時血糖: 110 mg/dL 未満を正常型の目安に、126 以上を当たる側に置いた
