## 3. ゲートで問うこと

1. **12 問のうち、どれを足すか**。とくに「セッションの案」の 8 問（c026〜c033）は、問いの語が記録の現場で使われるか、期待が妥当かを見てほしい
2. **c026「確定診断」**: 第 1 候補は「診断確度」でよいか。「プロブレム・診断名」を許容とするか、負例とするか
3. **c027「診断日」**: 「臨床的に認識された日時」（at0003）を指すと読んでよいか。c015 では at0003 は負例で、ここでは正解になる
4. **c033「脈拍」**: patient_blood_pressure.v1 は英語のラベルのままのテンプレート。日本語の問いの評価に入れるか
5. **「何も出ないのが正解」の問いを置くか**: v1 の q09 のコメントによれば「肥満度」は BMI と別の指標で、BMI のカードに着いてはいけない。
   いまの形式は期待が空の問いを採点できない（負例だけの問い）。置くなら、形式を足す計画を別に出す
