## レビューで決めてほしいこと

1. **血圧の項目が 2 つのテンプレートにある**（n001-1 の review）。CardiologyEncounter の「収縮期」（blood_pressure.v2）と、
   patient_blood_pressure.v1 の「Systolic」（blood_pressure.v1）。期待行は v2 だけ。文からは、どちらか決まらない。
   a001・a009・a010・a011 の 4 問（文は 11）にかかる。案:
   - (a) 文にテンプレートを書く（「循環器の診察記録の、収縮期血圧が…」）
   - (b) どちらを選んでも正解にする（期待行を 2 通り持つ）
   - (c) そのまま測り、「どちらのカードを選んだか」を別に数える
   セッションの推す案は (c)。接地の効果を見る測定なので、文を機械に合わせて直さない。ただし、正答率は下がりうる

   案では、base は「記録の出所（どのテンプレートの記録か）つきで」、chart は「どの帳票の記録かと一緒に」にした
3. **略語**（SBP、DBP。n001-2、n009-2）を、カルテの言葉として入れてよいか
4. **値の言い換え**（n004-3「FBS の値」）を入れるか。記録にある文字は「空腹時血糖」で、LLM に渡すカードの文に、この文字は無い。

5. カルテの言葉として不自然な文、臨床の意味が元の問いと変わっている文が無いか
6. 調整用の 3 問（t001〜t003）でよいか
